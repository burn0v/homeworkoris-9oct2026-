# Чат и список задач

**DISCLAIMER!!!** Основа кода была взята с прошлой домашки и классной работы!!

## Запуск

Из папки проекта откройте два терминала. В первом запустите сервер:

```bash
python3 server.py
```

Во втором запустите клиента:

```bash
python3 client.py
```

Клиент подключается к серверу на `127.0.0.1:5555`. Для подключения к серверу на другом компьютере адрес сервера в `client.py` должен совпадать с его адресом.

## Команды

- `/list` — запросить список задач и их статусов. В текущей реализации форматирование ответа сервера использует `task_name` вместо названия из текущей задачи, поэтому вывод списка может быть некорректным.
- `/addt <название>` — добавить задачу. В текущем клиенте название должно состоять из одного слова.
- `/done <номер>` — отметить задачу выполненной.
- `/quit` — отключиться от сервера.
- Любой другой непустой текст — отправить сообщение в чат.

При подключении клиент вводит имя пользователя; сервер не принимает пустые и уже занятые имена.

## Одновременная работа клиентов

Сервер принимает подключения в цикле и для каждого клиента запускает отдельный daemon-поток `handle_client`. Поэтому сервер может обслуживать несколько клиентов одновременно. Клиент также использует отдельный поток для получения сообщений, пока основной поток ждёт ввод команд.

## Синхронизация

На сервере используются блокировки `threading.Lock`:

- `clients_lock` защищает общий словарь подключённых клиентов при добавлении, удалении и получении списка клиентов для рассылки.
- `tasks_lock` защищает общий словарь задач при чтении и изменении задач. Под этой же блокировкой сервер назначает и увеличивает `next_task_id`.

Блокировки не дают потокам одновременно изменять общее состояние клиентов и задач.
